# Cranium Portfolio Map

## Role

`Cranium-Substrate-` is the conceptual and reference substrate layer. It provides structured contradiction evaluation, deterministic corpora, explanation families, and receipt-oriented analysis used to test and inform higher-level behavior.

## Canonical repository relationships

- **Authority boundary:** [cranium-kernel](https://github.com/worthwyl2022-cloud/cranium-kernel) — canonical transition and authority-state boundary.
- **Application and cognitive layer:** [Cranium-Core-](https://github.com/worthwyl2022-cloud/Cranium-Core-) — Android application and Core runtime integration.
- **Diligence workbench:** [Substrate-Workbench-Diligence-Proof-](https://github.com/worthwyl2022-cloud/Substrate-Workbench-Diligence-Proof-) — acquisition and diligence artifacts, proofs, and review navigation.

## Boundary guidance

Substrate outputs are analyses, contradiction findings, and evidence-oriented explanations. They do not independently grant authority or replace the kernel's validated transition boundary. Any promotion from analysis to authority must be evaluated by `cranium-kernel`.
