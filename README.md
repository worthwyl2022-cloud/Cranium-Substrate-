## Overview

Cranium Substrate is an enterprise-grade cognitive substrate engineered in idiomatic Kotlin. It provides autonomous metacognitive reasoning, contradiction resolution, and prompt-stream immune protection through protected semantic channels (Canon Lanes), immutable epistemic units (Cognitive Atoms), and deliberative consensus.

### Core Capabilities

- **Canon Lanes** — Priority-bound semantic channels (System Axiom → Enterprise Policy → Facts → Working Memory → Hypothetical)
- **Cognitive Atoms** — Immutable propositional units with provenance, confidence, and temporal decay
- **Contradiction Engine** — Pairwise polarity detection and resolution strategies
- **Deliberation Engine** — Multi-iteration dialectic consensus loop
- **Epistemic Immune Layer** — Real-time interception of jailbreaks, prompt injection, and axiom negation
- **Output Evaluator** — Policy and axiom alignment checks before release
- **Audit & Receipts** — Cryptographically signed execution receipts and benchmark harnesses
